## What's Changed

- Quay now runs on Ghostty 1.4.0's terminal engine.
- When a program on the server asks to read or change your clipboard, and your Ghostty config sets `clipboard-read` or `clipboard-write` to `ask`, Quay now asks you: Deny, Allow Once, or Allow for This Tab. Before, a read under `ask` (Ghostty's default) was left unanswered. The prompt never shows what's on your clipboard, and Return always means Deny, so a prompt that appears while you're typing can't be accepted by accident.
- Pasting text that could run commands, such as several lines into a shell, now asks Paste or Cancel and shows the text. Before, such a paste silently did nothing. `clipboard-paste-protection = false` in your Ghostty config turns the check off.
