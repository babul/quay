## What's Changed

- Reconnecting no longer clears the terminal. A new session continues on the screen the last one left, so the output you were reading survives the reconnect.
- A dropped session now retries on its own with backoff, which makes a remote reboot something a tab recovers from rather than something you restart.
- Press Space or Return on a disconnected tab to reconnect, and the tab now says so. ⌘R still works; before, it was the only way back and nothing on screen mentioned it.
- Connecting to a host that is still booting now gives up in seconds instead of burning about 75 seconds of silent retries, and a peer that vanishes without closing the connection is noticed instead of leaving the tab hanging on a dead socket.
- SFTP tabs report their real state. A usable lftp tab no longer sits on "Connecting…", a live session no longer offers to reconnect, and a dropped lftp connection dims the tab indicator instead of tearing down a prompt still holding your working directory, bookmarks, and queued transfers.
- lftp now uses interactive timeouts in place of its shipped defaults, which are built for unattended mirroring. A dead host reports in about 14 seconds and names itself, rather than hanging silently for over a minute.
- ⌘S now toggles the hosts sidebar and ⌘B toggles the snippets sidebar — ⌘B was the hosts sidebar before. In the snippet editor, Save moves to ⌘Return.
