## What's Changed

- The terminal now follows your macOS appearance. Switching to Light mode gives you a light terminal instead of staying dark. If you set a single `theme` in your own Ghostty config it still wins — use `theme = light:Some Light,dark:Some Dark` to follow the system there too.
- Scrollback now holds 100,000 lines. The previous limit was measured in bytes, not lines, which made the buffer far smaller than intended and discarded long output early.
- Lower memory use on long-lived sessions. The terminal engine now compresses idle scrollback, cutting its memory footprint substantially — which matters when you keep many tabs open.
- Faster tab opening, plus fixes for display and font edge cases that could disrupt a session.
